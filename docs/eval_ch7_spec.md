## 🎯 1. 단원 개요 및 교육과정 매핑
- **교과서 단원**: 2022 개정 중학교 1학년 수학 7단원 **Ⅶ. 입체도형** (교과서 210쪽 ~ 241쪽)
- **핵심 교육 목표**:
  1. 다면체와 정다면체의 뜻을 알고, 꼭짓점·모서리·면의 개수를 탐구하며, 모든 면이 합동인 정다각형이고 한 꼭짓점에 모인 면의 수가 같은 정다면체는 **오직 5가지뿐**임을 증명한다.
  2. 모든 다면체에서 성립하는 **오일러 다면체 정리 ($v - e + f = 2$)**를 탐구한다.
  3. 평면도형을 한 직선(회전축)을 중심으로 1회전 시켜 생기는 **회전체(원기둥, 원뿔, 원뿔대, 구)**를 관찰하고, 회전축을 포함하는 단면(선대칭도형)과 수직인 단면(항상 원)의 성질을 분석한다.
  4. 각기둥과 원기둥의 전개도를 통해 **기둥의 겉넓이($S = 2B + L$)**와 **부피($V = Sh$)**를 계산한다.
  5. 뿔의 부피가 기둥 부피의 $\frac{1}{3}$임을 물 채우기 실험으로 확인하고, **뿔의 겉넓이와 부피($V = \frac{1}{3}Sh$)**를 계산한다.
  6. 반구 표면에 끈을 감아 원의 넓이와 비교하여 **구의 겉넓이($S = 4\pi r^2$)**와 **구의 부피($V = \frac{4}{3}\pi r^3$)**를 유도한다.
  7. 원기둥에 꼭 들어맞는 구와 원뿔의 부피 비가 **원기둥 : 구 : 원뿔 = $3 : 2 : 1$**임을 아르키메데스 원리로 탐구한다.

### [INTENT-19] 🚫 정답 미노출 원칙 (Zero Answer Leakage in Placeholder/Hints)
- 모든 20개 서브스텝의 `<input>` 태그에서 `placeholder`나 안내 문구에 실제 채점 정답(숫자, 기호, 텍스트)이 노출되지 않아야 함. 오직 형식 안내만 허용.
- 정답 누출 적발 시 즉시 해당 서브스텝 및 전체 평가 반려.

### [INTENT-20] 🎨 캔버스 빈 공간 0건 원칙 (Zero Blank Canvas)
- 20개 서브스텝 전체에서 Two.js 캔버스(`canvas`) 요소가 반드시 렌더링되어야 하며, 빈 캔버스가 존재하지 않아야 함.
