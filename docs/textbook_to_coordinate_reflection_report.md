# 📘 교과서 지면 대비 `g1_coordinate.html` 반영 분석 및 표준 제작 지침서
> **부제**: 교과서 지면을 100% 디지털 인터랙티브 웹 앱으로 승화시킨 설계 철학, 페이지별(지면별) 정밀 대조 분석 및 타 단원 확장을 위한 레퍼런스 가이드

---

## 1. 🧭 개요 및 분석 목적

본 보고서는 **중학교 1학년 수학 4단원 「좌표평면과 그래프」(교과서 104쪽 ~ 129쪽)**의 실제 교과서 지면과 이를 기반으로 제작된 디지털 웹 애플리케이션 **`g1_coordinate.html`**을 **페이지 한 장 한 장(Page-by-Page) 전수 대조**하여, 사용자가 지시하고 구현한 **교과서 지면의 인터랙티브 웹 반영 메커니즘**을 총체적으로 규명한 표준 분석서입니다.

향후 제작될 다른 단원(1단원 소인수분해, 2단원 정수와 유리수, 3단원 문자와 식, 5단원 도형의 기초, 6단원 평면도형, 7단원 입체도형, 8단원 통계 등)의 개발 시 **본 보고서에서 정립된 충실도(Fidelity), 상호작용 수준(Interactivity), 화면 분할 규격, 채점 및 피드백 구조**를 절대적 개발 표준으로 준용합니다.

## 2. 🏛️ 교과서 디지털 전환의 5대 핵심 설계 철학

`g1_coordinate.html`에서 관찰되는 교과서 반영 방식은 단순한 '지면 텍스트의 웹 복사'가 아니라, **학습자가 능동적으로 수학적 대상을 조작하고 발견하는 대화형 인지 도구(Cognitive Tool)**로의 완전한 재창조입니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                        교과서 지면 (정적 매체)                         │
│   [도입 삽화] ───> [본문 개념 정의] ───> [확인 문제] ───> [창의 탐구]   │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ 1:1 대화형 디지털화 (Digital Twin)
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                 영서중 디지털 수학 웹 앱 (g1_coordinate.html)           │
├───────────────────────────────────┬────────────────────────────────────┤
│   [좌측 캔버스 영역 (50% Split)]   │   [우측 인터랙티브 카드 (50% Split)]│
│  • Two.js 동적 벡터 캔버스        │  • 단계별 학습 미션 배너 (KaTeX)    │
│  • 실시간 점 드래그 & 자석 스냅   │  • 인라인 괄호 빈칸 (.proof-input) │
│  • 물리 엔진 기반 실시간 시뮬레이터│  • 실시간 텍스트 정규화 채점(normTxt)│
│  • 투명 펜 드로잉 오버레이 레이어 │  • 즉각 오답 힌트 & 정답 축하 카드  │
└───────────────────────────────────┴────────────────────────────────────┘
```

1. **지면 1:1 무손실 매핑 (Zero Loss Mapping)**:
   - 교과서의 어느 한 줄, 단 하나의 문제나 삽화도 누락하지 않고 고유한 서브스텝 코드(`SubStepCode`)로 1:1 분할 매핑합니다.
2. **동적 캔버스화 (Static to Dynamic Canvas)**:
   - 교과서에 인쇄된 멈춰있는 수직선, 좌표평면, 그래프를 학생이 직접 점을 잡고 끌거나(`Drag & Snap`), 클릭하여 점을 찍거나(`Plotting`), 슬라이더를 밀어 변화를 관찰하는 살아있는 캔버스로 변환합니다.
3. **오개념 사전 차단 및 스포일러 방지 (Zero Answer Leakage)**:
   - 교과서의 답이나 사분면 부호($(+, +)$ 등)를 미리 캔버스에 적어두지 않고, 학생이 조작을 통해 직접 규칙성을 발견한 후 빈칸에 입력하도록 유도합니다.
4. **인라인 맥락형 빈칸 채점 (Contextual Inline Blanks)**:
   - 정답 입력창을 별도의 무미건조한 시험지 형태가 아닌, 교과서 문장의 호흡 속에 자연스러운 괄호 형태(`<input class="proof-input-text">`)로 배치합니다.
5. **학습 연속성 및 상태 영속화 (State & LMS Sync)**:
   - 탭이나 페이지를 이동해도 학생이 작성하던 내용이 지워지지 않도록 로컬 캐시(`savedFormInputs`)에 보존하고, 교사용 관제 대시보드 및 실시간 LMS 전송을 지원합니다.

## 4. 🔬 지면별(페이지별) 정밀 심층 대조 분석 (Deep Dive)

### 4.1 교과서 104~105쪽: 단원 도입 및 [되짚어 보기] $\implies$ 서브스텝 `0-1`, `0-2`, `0-3`

#### [교과서 지면 구성]
- **단원 표지 (104쪽)**: 자동차 속도와 이동 거리 그래프 삽화, 대단원 학습 목표.
- **되짚어 보기 (105쪽)**:
  - 1번: 초등 5~6학년 대응 관계 (표: $\Box$가 1, 2, 3, 4, 5, 6일 때 $\triangle$가 3, 6, 9, ...)
  - 2번: 중1 정수와 유리수 (수직선 위 점 $A, B, C$에 대응하는 수 구하기)
  - 3번: 중1 문자의 사용과 식의 값 ($x=2$일 때 $4x$, $x-5$, $8/x$의 값 계산)

#### [웹 애플리케이션 구현 방식]
1. **서브스텝 분할 및 해금 연동**:
   - 105쪽의 3문제를 하나의 긴 페이지에 나열하지 않고 `0-1`, `0-2`, `0-3`으로 개별 분할하여 집중도 극대화.
   - 3문제를 모두 통과해야 비로소 본단원인 `4.1 순서쌍과 좌표(1-1)` 탭이 자동으로 해금(`unlockNextStep(0)`)되도록 설계하여 **선수지식 결손 방지**.
2. **좌측 캔버스 시각화**:
   - `0-1`: `drawTableCanvas`가 표 형태를 벡터 그래픽으로 렌더링하고, 현재 계산 중인 행/열을 하이라이트.
   - `0-2`: `drawNumberLineCanvas`가 수직선의 원점 $0$을 중심으로 음수/양수 눈금 및 분수 지점($-3.5 = -7/2$)을 정확한 비례 간격으로 표기.
3. **우측 폼 및 유연한 채점**:

## 5. 🧩 교과서 요소를 웹 인터랙션으로 변환한 8대 핵심 디자인 패턴

다른 모든 단원 제작 시 다음 **8대 변환 공식**을 기계적으로 적용할 수 있을 정도로 엄격히 준수합니다.

```
[패턴 1] 정적 삽화/다이어그램 ───> Two.js 벡터 애니메이션 및 기하 렌더러
[패턴 2] 본문 개념 설명 ─────────> 실시간 드래그 & 스마트 자석 스냅 인터랙터
[패턴 3] 좌표/위치 찾기 문항 ────> 다중 점 목표 배치 미션 & 실시간 상태 뱃지
[패턴 4] 보조선/작도형 문항 ─────> 투명 펜 드로잉 오버레이 레이어
[패턴 5] 개념 정의 및 수식 ─────> 인라인 괄호 빈칸 (.proof-input-text) & KaTeX
[패턴 6] 오개념/주의사항 ────────> 스포일러 방지형 [주의 / 핵심 팁] 카드
[패턴 7] 제출 및 정답 확인 ─────> 폭죽(Confetti) + 음향 + 해설 요약 카드 전환
[패턴 8] 교과서 흐름/페이지 ─────> 상단 대단원 탭 + 하단 서브스텝 필(Pills)
```

### 패턴 1: 정적 삽화 $\rightarrow$ Two.js 동적 캔버스
- 교과서의 그림을 캡처해서 붙여넣지 않고, 순수 Two.js 코드로 직접 그립니다.
- 해상도 독립적(Retina 지원)이며, 크기 조절 시 깨짐이 전혀 없습니다.

### 패턴 2: 본문 개념 $\rightarrow$ 실시간 드래그 & 스마트 자석 스냅
- 수학적 대상을 직접 잡고 움직일 수 있어야 합니다.
- 마우스/터치 좌표를 격자 정수 단위로 자동 반올림 스냅하여 학생의 조작 피로도를 줄이고 정밀성을 확보합니다.
```javascript
let rx = Math.round((mx - cx) / step);
let ry = Math.round((cy - my) / step);
rx = Math.max(-maxGrid, Math.min(maxGrid, rx));
ry = Math.max(-maxGrid, Math.min(maxGrid, ry));
```

### 패턴 3: 다중 점 목표 배치 미션
- "점을 좌표평면에 나타내시오" 문제는 점을 목표 위치로 옮기는 미션으로 승화시킵니다.
- `state.pointsPlaced = { A: false, B: false, ... }`로 관리하며 실시간 판정합니다.

### 패턴 4: 투명 펜 드로잉 오버레이 레이어
- 작도나 도형 보조선 긋기가 필요한 문항에서는 Two.js 위에 별도의 투명 Canvas를 얹어 필기가 가능하도록 합니다. 필요 없는 단계에서는 자동으로 숨기고 이벤트 간섭을 차단합니다.

### 패턴 5: 인라인 괄호 빈칸 및 정규화 채점
- `<input class="proof-input-text">`로 문장 속에 자연스럽게 빈칸을 뚫습니다.
- `normTxt()`로 공백 제거 및 대소문자 무시, 한국어 어미 유연성(`.includes('다르')`), 분수/소수 동시 허용을 구현합니다.

### 패턴 6: 스포일러 방지 원칙 (Zero Answer Leakage)
- **규칙 3 준수**: `placeholder`에는 절대로 정답 수치나 텍스트를 노출하지 않습니다. 오직 `placeholder="좌표 기호 입력"`, `placeholder="수 입력"`과 같은 형식 안내만 제공합니다.

### 패턴 7: 피드백 및 전환
- 오답 시: 구체적인 힌트가 담긴 빨간 경고창(`.proof-error-notice`).
- 정답 시: 경쾌한 사운드 + 색종이 폭죽(`launchConfetti()`) + 깔끔한 정답 해설 카드(`.verified-answer-card`) 전환 + [🚀 다음 단계로 진행하기] 버튼 노출.

### 패턴 8: 단계적 잠금 및 내비게이션 위계
- 이전 활동을 완료해야 다음 서브스텝이 해금되는 빗장 잠금(`🔒`) 구조.
- 교사는 마스터 패스워드(`260523`, `260831`)를 통해 원클릭으로 전 페이지를 해금하고 학생 진도를 통제할 수 있습니다.
