### [INTENT-04] 0-1 초등 복습: [□를 사용한 식과 수평 저울] (교과서 68쪽)
- 좌측 캔버스에 왼쪽 접시($3 \times \square + 5$)와 오른쪽 접시($20$)의 양팔 저울 시각화.
- $\square$ 값을 변경하면 저울의 기울기가 동적으로 계산되어 평형을 이룰 때 수평 렌더링.
- `check01Submit()`에서 $\square = 5$ 채점 정상 동작.

### [INTENT-05] 1-1 교과서 70쪽 생각열기: [아이스크림 구매 영수증 시뮬레이터]
- 1개 3500원인 아이스크림의 수량 $x$를 조절하는 슬라이더 인터랙션.
- 슬라이더 조작 시 바코드, 개수 $x$, 단가 3500원, 총액 $3500x$ 원이 실시간 영수증에 인쇄되는 애니메이션.
- `check11Submit()`에서 $3500x$, $3500a + 5000b$ 문장 식 채점 정상 동작.

### [INTENT-06] 1-3 교과서 74쪽 생각열기: [독서 진행 게이지와 식의 값]
- 400쪽 책을 하루에 10쪽씩 $x$일 읽었을 때 남은 쪽수 $400 - 10x$ 시뮬레이터.
- 일수 $x$ 슬라이더를 조작하면 Two.js 게이지 바에서 읽은 쪽수(파란색)와 남은 쪽수(오렌지색)가 동적으로 갱신.
- `check13Submit()`에서 $400 - 10x$ 및 $x=5$일 때 $350$쪽 채점 정상 동작.

### [INTENT-07] 2-1 교과서 76~77쪽: [다항식 구조 카드 분해기]
- 다항식 $-3x^2 + 5x - 7$을 각 항 카드($-3x^2$, $+5x$, $-7$)로 분해하여 시각화.
- 계수, 상수항, 최고차수를 버튼으로 하이라이트 가능.
- `check21Submit()`에서 계수(5), 상수항(-7), 차수(2), 일차식 판별(예) 채점 정상 동작.

### [INTENT-08] 2-2 교과서 78쪽: [직사각형 면적 모델과 분배법칙]
- 단항식과 수의 곱셈 $2x \times 3 = 6x$ 및 분배법칙 $3(x + 2) = 3x + 6$을 Two.js 직사각형 분할 면적으로 렌더링.
- 가로/세로 길이 변경 시 면적 조각들이 시각적으로 분할 및 합체.
- `check22Submit()`에서 $6x$, $-8x + 12$, $2x - 3$ 채점 정상 동작.

### [INTENT-09] 2-3 교과서 80쪽: [동류항 대수 막대 타일 모으기]
- $x$ 타일(녹색 긴 막대)과 $1$ 타일(노란색 작은 정사각형)을 인터랙티브하게 배치.
- [동류항 모으기] 클릭 시 같은 타일끼리 정렬되고 합산($6x - 2$)되는 Two.js 모션.
- `check23Submit()`에서 동류항 판별 및 합 계산($6x - 2$) 채점 정상 동작.

### [INTENT-10] 3-1 교과서 84쪽: [방정식 vs 항등식 판별 저울]
- $x$ 슬라이더를 조절할 때, 항등식($2x+3x=5x$)은 어떤 $x$에서도 항상 완벽한 평형을 유지하고, 방정식($2x=6$)은 오직 $x=3$에서만 찰칵 수평을 맞추는 인터랙티브 저울.
- `check31Submit()`에서 방정식과 항등식 분류 채점 정상 동작.

### [INTENT-11] 3-3 교과서 88~89쪽: [등식의 성질 양팔 저울 실험실]
- 양팔 저울의 좌변($x-3$)과 우변($5$)에 대하여 [+3 더하기], [-3 빼기], [×2 곱하기], [÷2 나누기] 버튼 제공.
- 양변에 동일 연산 수행 시 수평이 유지되면서 최종적으로 $x=8$로 단순화되는 과정 시뮬레이션.
- `check33Submit()`에서 등식의 성질에 따른 연산 수치 채점 정상 동작.

### [INTENT-12] 4-1 교과서 92쪽: [이항(移項) 애니메이션 시뮬레이터]
- 방정식 $5x - 2 = 2x + 3$에서 [이항 실행]을 누르면 우변의 $+2x$가 좌변으로 포물선을 그리며 $-2x$로 부호가 바뀌고, 좌변의 $-2$가 우변으로 넘어가며 $+2$로 바뀌는 모션.
- 이항 결과 $3x = 5$가 도출되는 시각화.
- `check41Submit()`에서 이항 후 식($3x = 5$) 및 부호 반전 원리 채점 정상 동작.

### [INTENT-13] 5-2 교과서 102쪽 창의융합: [생각한 수 맞추기 수학 마술사]
- 학생이 임의의 수 $x$를 정하고 마술 단계($+4 \rightarrow \times 2 \rightarrow -6 \rightarrow \div 2 \rightarrow -x$)를 실행하면 항상 결과가 1로 귀결되는 대수 마술.
- 카드가 뒤집히며 대수식 변형 과정($(2x+2)/2 - x = 1$)이 시각적으로 증명됨.
- `check52Submit()`에서 최종 결과(1) 및 $x$ 소거 원리 채점 정상 동작.

### [INTENT-14] 🌟 중1 좌표평면(g1_coordinate.html) 대비 질적 완성도 상시 벤치마크
- 영서중 기준 페이지인 `g1_coordinate.html`과 7대 질적 규격(Two.js 동적 캔버스, 4대 모달, 5x5 대시보드, 교과서 1:1 서브스텝 실험실, LMS 동기화, normTxt 채점 UX, 5종 사운드 시스템)을 비교하여 **90% 이상 일치 시에만 최종 합격**.

### [INTENT-15] 🚫 정답 미노출 원칙 (Zero Answer Leakage in Placeholder/Hints)
- 학생이 정답을 입력하는 빈칸의 `placeholder`, 안내 문구, 힌트 예시 등에 **해당 문제의 실제 정답(숫자, 수식, 텍스트 등)을 절대 직접 노출하지 않음**.
- `placeholder`는 오직 입력 형식 안내(예: `placeholder="일차식 입력 (예: ax+b)"`, `placeholder="해 (숫자)"`) 목적으로만 구성.
- 모든 입력란의 플레이스홀더를 전수 감사하여 실제 정답 누출 발견 시 즉시 반려.
