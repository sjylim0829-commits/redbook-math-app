## 🎯 1. 핵심 아키텍처 및 기본 기능 설계 의도 (Essential Architecture)

### [INTENT-01] 🔐 로그인 모듈 및 교사 권한 (필수 탈락 기준)
- **INTENT-01-A (로그인 UI)**: 학번 인풋(`student-id`), 비밀번호 인풋(`student-name`), 로그인 버튼, 교사 계정 접속 버튼(`openTestLoginModal`)이 모두 정상 배치되어야 함.
- **INTENT-01-B (학생 로그인)**: 학번 `10101`, 비밀번호 입력 후 로그인 시 활동 뷰(`view-activity`)로 전환되며, `0-1`은 기본 해금(🔓), 이후 단계는 잠금(🔒) 상태를 유지해야 함.
- **INTENT-01-C (마스터 비밀번호 바이패스)**: 학번 또는 비밀번호에 교사 마스터 번호 `260523` 또는 `260831` 입력 시 교사 관리자 모드로 진입하고 전체 26개 서브스텝이 프리패스 해금되어야 함.
- **INTENT-01-D (교사 계정 접속 버튼 및 모달 팝업)**: `🔑 교사 계정 접속` 버튼 클릭 시 `#secure-password-modal`이 화면에 `display: flex`로 즉시 나타나야 함. 이후 모달 내에서 `260523` 또는 `260831` 입력 후 확인 시 교사 관리자 모드로 즉시 로그인되어야 함.

### [INTENT-02] 🟡 노란색 정답 입력 빈칸 규격
- 모든 정답 입력 필드(`.proof-input-text`)는 미입력/기본 상태에서 노란색 배경(`background-color: #fef08a`, 테두리 `2px solid #eab308`)을 유지해야 함.
- 커서 포커스 시 흰색(`background-color: #ffffff`, 테두리 `#3b82f6`)으로 전환되어 시인성을 극대화해야 함.

### [INTENT-03] 🏛️ 4대 모달 및 교사 관제 시스템
- `#secure-password-modal`: 교사 비밀번호 인증 모달 완비.
- `#unlock-boundary-modal`: 학생 진도 범위 설정 모달 완비.
- `#teacher-dashboard-modal`: 실시간 5x5 학생 관제 대시보드 완비.
- `#student-zoom-modal`: 1:1 학생 확대 관제 모달 완비.

## 🚫 3. 필수 검증 및 6대 무조건 반려 원칙

서브에이전트는 다음 6대 항목 중 **단 하나라도 위반 시 무조건 반려(`REJECT`)**합니다:

1. **[REJECT-01] 학생 로그인 실패**: `10101` 학생 로그인 후 활동 뷰 정상 전환 및 `0-1` 서브스텝 활성화 실패 시.
2. **[REJECT-02] 교사 마스터 비밀번호(260523, 260831) 및 모달 실패**: 마스터 바이패스 또는 `🔑 교사 계정 접속` 버튼 모달 인증 실패 시.
3. **[REJECT-03] 정답 미노출 원칙 위반 (Zero Answer Leakage)**: 26개 서브스텝의 어떤 `placeholder`나 라벨에도 실제 정답이 직접 노출되었을 때.
4. **[REJECT-04] 좌측 캔버스 비어있음 (Blank Canvas)**: 26개 서브스텝 중 단 하나의 서브스텝이라도 Two.js 그래픽 미작동 시.
5. **[REJECT-05] 화면 고정 버그 (Screen Freeze) 및 잔류 애니메이션**: `loadSubStep` 진입 시 `activeLerpAnimations` 취소 누락 또는 `startSmoothLerp` 수렴 실패 시.
6. **[REJECT-06] 질적 완성도 90% 미달**: 26개 서브스텝 전수 평가 점수가 90% 미만일 때.
