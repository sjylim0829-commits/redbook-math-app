## 🔬 2. 교과서 1:1 연계 10대 인터랙티브 시뮬레이터 설계 의도

### [INTENT-04] 0-1 약수 타일 직사각형 분할기 (교과서 초등 복습)
- 12개의 타일을 $1 \times 12$, $2 \times 6$, $3 \times 4$ 직사각형 배열로 전환할 수 있는 시뮬레이터.
- `setTileArray(rows, cols)` 조작 시 캔버스에 직사각형 타일 격자와 약수 쌍(1, 12, 2, 6, 3, 4)이 실시간 렌더링되어야 함.
- `check01Submit()`에서 12의 약수 채점 및 정답뷰 렌더링 정상 동작.

### [INTENT-05] 1-1 자연수 약수 개수 분류 저울 (교과서 12쪽 생각열기)
- 1부터 10까지의 수를 약수의 개수(1개: 1 / 2개: 2, 3, 5, 7 / 3개 이상: 4, 6, 8, 9, 10)에 따라 분류하는 시뮬레이터.
- `classifyNumber(num, group)` 조작판과 바구니가 활성화되어야 함.
- `check11Submit()`에서 약수 개수 분류 채점 정상 동작.

### [INTENT-06] 1-3 에라토스테네스의 체 단계별 체질기 (교과서 15쪽 활동)
- 1~50 수 격자판에서 버튼 조작으로 소수를 걸러내는 인터랙티브 체.
- `stepSieve(step)`: 1단계(1 지우기) $\rightarrow$ 2단계(2 남기고 2배수 지우기) $\rightarrow$ 3단계(3 남기고 3배수 지우기) $\rightarrow$ 4단계(5배수 지우기) $\rightarrow$ 5단계(7배수 지우기) 순차 체질 애니메이션.
- `check13Submit()`에서 50 이하 소수 개수(15개) 채점 정상 동작.

### [INTENT-07] 2-1 거듭제곱 블록 배가 시뮬레이터 (교과서 18쪽)
- 밑과 지수를 조작하여 거듭제곱을 시각화하는 시뮬레이터.
- `setPowerSim(base, exp)` 호출 시 $2^1=2$, $2^2=4$, $2^3=8$, $2^4=16$, $2^5=32$ 블록이 동적으로 증식하고 리드아웃 뱃지가 갱신되어야 함.
- `check21Submit()`에서 밑과 지수, 거듭제곱값 채점 정상 동작.

### [INTENT-08] 2-2 소인수분해 가지치기 트리 빌더 (교과서 20~21쪽)
- 수(예: 36 또는 60)를 가지치기(Tree) 또는 나눗셈으로 분해하는 인터랙티브 빌더.
- `stepFactorTree(target)` 호출 시 캔버스에 수형도 가지가 뻗어나가며 최종 소수 잎($2 \times 2 \times 3 \times 3 = 2^2 \times 3^2$)이 렌더링되어야 함.
- `check22Submit()`에서 36과 60의 소인수분해 결과 채점 정상 동작.

### [INTENT-09] 2-3 소인수분해 격자표 약수 생성기 (교과서 23쪽)
- 소인수 거듭제곱을 축으로 하는 2차원 곱셈표 격자 시뮬레이터.
- $72 = 2^3 \times 3^2$의 행 $(1, 2, 4, 8)$과 열 $(1, 3, 9)$가 교차하여 12개의 모든 약수가 채워지는 인터랙티브 테이블.
- `check23Submit()`에서 약수 목록 및 개수 공식 $(3+1)(2+1)=12$ 채점 정상 동작.

### [INTENT-10] 3-1 두 수의 공약수 벤다이어그램 (교과서 26~27쪽)
- 두 수(18과 24)의 약수를 벤다이어그램의 A영역, B영역, 교집합영역으로 분류하는 시뮬레이터.
- `setVennFactors(a, b)` 호출 시 공약수(1, 2, 3, 6)와 최대공약수(6)가 중앙에 강조되어야 함.
- `check31Submit()`에서 공약수와 최대공약수 채점 정상 동작.

### [INTENT-11] 3-2 소인수 거듭제곱 비교 최대공약수 저울 (교과서 28쪽)
- 소인수분해 식($2^2 \times 3$, $2^3 \times 3^2$)을 비교하여 공통 소인수의 작은 지수를 선택하는 저울.
- `compareGcdPowers()` 조작 시 각 소인수별 최소 지수가 하단에 취합되어 $\text{GCD} = 2^2 \times 3 = 12$가 도출되어야 함.
- `check32Submit()`에서 거듭제곱 표현 최대공약수 채점 정상 동작.

### [INTENT-12] 4-2 톱니바퀴 맞물림 회전 시뮬레이터 (교과서 34쪽 활동)
- 톱니 24개인 바퀴 A와 36개인 바퀴 B가 서로 맞물려 회전하는 동적 시뮬레이터.
- `rotateGears(step)` 조작 시 두 바퀴가 맞물려 회전하며 처음 위치로 돌아올 때까지 A바퀴 3회전, B바퀴 2회전, 최소공배수 72톱니가 실시간 동기화되어야 함.
- `check42Submit()`에서 회전수와 최소공배수 채점 정상 동작.

### [INTENT-13] 5-2 몬드리안 직사각형 분할 창의융합 (교과서 38쪽)
- 최대공약수를 한 변으로 하는 가장 큰 정사각형 타일로 직사각형을 꽉 채워 분할하는 인터랙티브 실험실.
- 가로 36, 세로 24 직사각형에 변의 길이 12인 정사각형 타일 6장 배치 시각화.
- `check52Submit()`에서 최대공약수 타일 크기(12)와 필요 장수(6장) 채점 정상 동작.

### [INTENT-15] 🚫 정답 미노출 원칙 (Zero Answer Leakage in Placeholder/Hints)
- 학생이 정답을 입력하는 빈칸의 `placeholder`, 안내 문구, 힌트 예시 등에 **해당 문제의 실제 정답(숫자, 수식, 텍스트 등)을 절대 직접 노출하지 않음**.
- `placeholder`는 오직 입력 형식 안내(예: `placeholder="약수를 쉼표로 나열"`, `placeholder="최대공약수 (숫자)"`, `placeholder="소수 또는 합성수"`) 목적으로만 구성.
- 모든 입력란의 플레이스홀더를 전수 감사하여 실제 정답 누출 발견 시 즉시 반려.

### [INTENT-16] ⚙️ 절전형 물리 애니메이션 엔진 및 화면 고정 방지 표준
- 전 단원 공통 물리 애니메이션 함수 `startSmoothLerp(key, getter, setter, targetVal, onFrame, onComplete, speed = 0.12)` 탑재.
- 내부 실수 변수(`currentFloat`) 기반 지수 감속 수렴 및 임계 도달(`|diff| < 0.02 || |diff*speed| < 0.005`) 시 즉시 강제 안착 및 `requestAnimationFrame` 완전 종료.
- **`loadSubStep` 진입 시 `activeLerpAnimations` 잔여 애니메이션 전량 취소** (`cancelAnimationFrame` 호출 후 삭제)하여 페이지 전환 시 이전 시뮬레이터로 인한 좌측 캔버스 고정 현상 100% 차단.
- 시뮬레이터 콜백 내 `state.subStep === expectedCode` 가드로 오염 방지.
