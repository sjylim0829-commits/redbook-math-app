## 🎯 1. 핵심 아키텍처 및 기본 기능 설계 의도 (Essential Architecture)

### [INTENT-01] 🔐 로그인 모듈 및 교사 권한 (필수 탈락 기준)
- **INTENT-01-A (로그인 UI)**: 학번 인풋(`student-id`), 비밀번호 인풋(`student-name`), 로그인 버튼, 교사 계정 접속 버튼(`openTestLoginModal`)이 모두 정상 배치되어야 함.
- **INTENT-01-B (학생 로그인)**: 학번 `10101`, 비밀번호 입력 후 로그인 시 활동 뷰(`view-activity`)로 전환되며, `0-1`은 해금(🔓), 이후 단계는 잠금(🔒) 상태여야 함.
- **INTENT-01-C (마스터 비밀번호 바이패스)**: 학번 또는 비밀번호에 마스터 번호 `260523` 입력 시 교사 관리자 모드로 진입하고 전체 서브스텝이 프리패스 해금되어야 함.
- **INTENT-01-D (교사 계정 접속 버튼 및 모달 팝업)**: [필수 평가 항목] `🔑 교사 계정 접속` 버튼 클릭 시 아무 반응이 없거나 런타임 오류가 발생하면 안 되며, `#secure-password-modal`이 화면에 `display: flex`로 즉시 나타나야 함. 이후 모달 내에서 `260523` 입력 후 확인 시 교사 관리자 모드로 즉시 로그인되어야 함.
- **중대 실패 기준 (무조건 반려)**: 학생 로그인, 마스터 바이패스, 또는 **교사 계정 접속 버튼 클릭/모달 팝업** 중 단 하나라도 실패할 경우, 전체 완성도 점수와 상관없이 **무조건 반려(REJECT)**.

### [INTENT-02] 🟡 노란색 정답 입력 빈칸 규격
- 정답 입력 필드(`.proof-input-text`, `.proof-input-textarea`)는 커서를 놓기 전 노란색 배경(`background-color: #fef08a`, 테두리 `2px solid #eab308`)을 유지해야 함.
- 커서 포커스 시 흰색(`background-color: #ffffff`, 테두리 `#3b82f6`)으로 전환되어야 함.

### [INTENT-03] 🏛️ 4대 모달 및 관리 시스템
- `#secure-password-modal`: 교사 비밀번호 인증 모달 존재.
- `#unlock-boundary-modal`: 학생 진도 범위 해금 모달 존재.
- `#teacher-dashboard-modal`: 실시간 학생 제출 현황 모달 존재.
- `#student-zoom-modal`: 1:1 학생 확대 관제 모달 존재.
- 상단 헤더에는 불필요한 별도 교사 버튼이 없어야 함.

## 🔬 2. 교과서 1:1 연계 인터랙티브 시뮬레이터 설계 의도 (Interactive Simulators)

### [INTENT-04] 0-1, 0-2 되짚어보기 (초등 수직선 및 연산)
- `0-1`: 분수 덧셈(`1/3 + 1/2 = 5/6`)과 소수 곱셈(`0.4 * 0.5 = 0.2`) 채점 로직 정상 동작.
- `0-2`: 수직선 눈금 읽기 (점 A = 3, 점 B = 1.5) 채점 및 핀 배치 동작.

### [INTENT-05] 1-1 교과서 50쪽 생각열기: [로봇 위치 이동 시뮬레이터]
- `setupSubstepSimulator`를 통해 `#interactive-sim-controller`에 로봇 조작판이 활성화되어야 함.
- `moveRobot(1)` 실행 시 `simState.robotPos`가 +1 증가하고, 상단 뱃지 텍스트가 갱신되어야 함.
- `moveRobot(-1)` 실행 시 -1 감소, `resetRobot()` 실행 시 원점(0)으로 복귀해야 함.
- `runRobotMission()` 실행 시 교과서 미션인 "+3m 전진 후 -5m 후진 ➔ 최종 -2m" 궤적이 순차적으로 실행되어야 함.
- `check11Submit()`에서 최종 위치 `-2`, 영하 `-7`, 손해 `-500` 정답 판정 정상 동작.

### [INTENT-06] 1-2 & 1-3 교과서 52~53쪽: [수직선 점 마그네틱 배치기]
- 점 A, B, C를 버튼(`setPointP12`)으로 각각 목표 좌표(+3, +1.5, -2.5, -3.5)에 배치할 수 있어야 함.
- `simState.p12Points` 객체에 좌표가 저장되고 캔버스에 깃발과 수치가 렌더링되어야 함.
- `check12Submit()`에서 정수 목록과 0의 성질 채점, `check13Submit()`에서 유리수 O와 -2.5 채점 정상 동작.

### [INTENT-07] 1-4 교과서 54~55쪽: [원점 거리(절댓값) 측정 줄자]
- `setAbsPos(val)` 함수를 호출하여 점 P의 위치를 변경할 수 있어야 함.
- 점 P가 `-5`일 때 원점으로부터의 거리 `5` 및 절댓값 `|-5| = 5`가 디스플레이(`#abs-readout`)와 캔버스에 시각화되어야 함.
- `check14Submit()`에서 $|-5|=5$, $|+2.7|=2.7$, 절댓값 4인 수(+4, -4) 채점 정상 동작.

### [INTENT-08] 2-1 교과서 56~57쪽: [수직선 대소 비교 저울]
- `setCompare(a, b)`를 통해 두 수의 대소 판정 (`+3 > -4`, `-5 < -2`)이 디스플레이(`#compare-readout`)에 갱신되어야 함.
- `check21Submit()`에서 부등호 `>, <, <` 정답 판정 정상 동작.

### [INTENT-09] 3-1 교과서 60~62쪽: [양(+)·음(-) 칩 상쇄 실험실]
- `addChip('blue')`, `addChip('red')`로 칩을 추가하고 카운터(`#chip-counter`)가 업데이트되어야 함.
- `cancelChipPairs()` 호출 시 `simState.chipCancelled = true`가 되며, 쌍 상쇄 후 남은 칩과 계산 공식(`(+3)+(-5)=-2`)이 도출되어야 함.
- `resetChips(b, r)`로 교과서 예제 상태로 재설정 가능해야 함.
- `check31Submit()`에서 덧셈 4문항(+10, -13, +6, -6) 채점 정상 동작.

### [INTENT-10] 3-2 교과서 61쪽: [수직선 2단계 화살표 덧셈기]
- `stepArrow(step)`을 통해 1단계(0에서 +3 발사), 2단계(-5 발사), 3단계(최종 -2 깃발)가 순차적으로 시각화되어야 함.
- `check32Submit()`에서 교환법칙, 결합법칙, 계산값(+5) 채점 정상 동작.

### [INTENT-11] 4-1 교과서 68~70쪽 생각열기: [속도×시간 곱셈 시뮬레이터]
- `setMultSim(v, t)`를 통해 속도와 시간을 변경하고 `mult-readout`에 `(-3) × (-2) = +6`이 갱신되어 음수×음수=양수 증명 가능해야 함.
- `check41Submit()`에서 (+12, -30, +56) 채점 정상 동작.

### [INTENT-12] 5-2 교과서 76~77쪽 프로젝트: [세계 도시 기온차 수직선 온도계]
- `setThermCities(a, b)`를 통해 두 도시(서울 +5, 모스크바 -12)의 수은주와 기온차(17℃)가 렌더링되어야 함.
- `check52Submit()`에서 기온차 `17` 채점 및 대단원 완료 화면(`renderVerifiedAnswerView`) 호출 정상 동작.

### [INTENT-13] 📝 채점 및 피드백 전환
- 모든 채점 함수는 `normTxt` 정규화를 통과하여 공백 및 형식 차이에 유연해야 함.
- 정답 제출 시 `renderVerifiedAnswerView`가 실행되어 녹색 축하 카드와 [🚀 다음 단계로 진행하기 ➔] 버튼이 나타나야 함.

### [INTENT-14] 🌟 중1 좌표평면(g1_coordinate.html) 대비 질적 완성도 상시 벤치마크 (Qualitative Parity Benchmark)
- **비교 대상 기준**: 영서중 대표 기준 페이지인 `g1_coordinate.html`
- **질적 평가 7대 영역**:
  1. **Two.js 인터랙티브 그래픽 충실도**: 단순 정적 이미지가 아닌 애니메이션, 드래그/스냅, 실시간 수치 연동 (좌표평면 대비 동등 이상)
  2. **4대 모달 및 교사 관제 시스템**: 단원 맵, 학습 목표, 교사 비밀번호 인증, 학생 해금 범위 설정 모달 완비 (좌표평면과 100% 동일)
  3. **교사 5x5 관제 대시보드 (`#view-teacher-dashboard`)**: 실시간 학급 전환 및 모니터링 카드 구조 (좌표평면과 100% 동일)
  4. **교과서 1:1 서브스텝 구현 밀도**: 교과서 지면의 생각열기/활동/창의융합을 모두 전용 인터랙티브 실험실로 구현 (90% 이상 완성도)
  5. **LMS 클라우드 동기화 및 자동 저장**: `js/lms-integration-g1.js` 호환 및 크로스 디바이스 진행도 보존
  6. **채점 UX 및 단계적 해금**: 노란색 빈칸(`#fef08a`), 즉각적 성공 카드, 자동 다음 단계 해금
  7. **사운드 피드백**: Web Audio API 기반 5종 효과음(`pop`, `click`, `success`, `error`, `unlock`)
- **통과 기준**: 좌표평면 대비 질적 완성도 지표 **90% 이상** 필수 달성.

### [INTENT-15] 🚫 정답 미노출 원칙 (Zero Answer Leakage in Placeholder/Hints)
- 학생이 정답을 입력하는 빈칸의 `placeholder`, 안내 문구, 힌트 예시 등에 **해당 문제의 실제 정답(숫자, 수식, 텍스트 등)을 절대 직접 노출하지 않음**.
- `placeholder`는 오직 입력 형식 안내(예: `placeholder="부호와 수"`, `placeholder="분수 입력 (예: a/b)"`) 목적으로만 구성.
- 모든 입력란의 플레이스홀더를 전수 감사하여 실제 정답 누출 발견 시 즉시 반려.
