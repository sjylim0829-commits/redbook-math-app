## 🎲 Step 2-2 수학적 확률의 계산 (p = a / n) 캔버스 랩 세부 분석

### 1. 교과서 원본 연계 (동아출판 258~259쪽 개념 탐구 2)
- **주제**: 수학적 확률의 정의 ($p = \frac{a}{n}$) 및 가영이의 오개념 교정 (각 결과가 일어날 가능성이 같지 않은 경우)
- **학습 내용**:
  - **개념 정리 (258쪽)**: 어떤 실험이나 관찰에서 일어날 수 있는 모든 경우의 수가 $n$이고, 각 경우가 일어날 가능성이 같을 때, 사건 $A$가 일어나는 경우의 수가 $a$이면 사건 $A$가 일어날 확률 $p$는:
    $$p = \frac{\text{사건 } A\text{가 일어나는 경우의 수}(a)}{\text{모든 경우의 수}(n)} = \frac{a}{n}$$
  - **문제 1 (258쪽)**: 1개의 주사위를 던질 때:
    - (1) 홀수의 눈이 나올 확률: $\{1, 3, 5\} \to \frac{3}{6} = \frac{1}{2}$.
    - (2) 소수의 눈이 나올 확률: $\{2, 3, 5\} \to \frac{3}{6} = \frac{1}{2}$.
  - **생각 열기 (259쪽 - 가영이의 오류 교정)**:
    - 주머니에 **검은 공 6개, 흰 공 4개**가 들어있을 때, 가영이의 주장: *"나올 수 있는 공의 색은 검은색과 흰색의 2가지이므로 흰 공이 나올 확률은 $1/2$이다."*
    - **수학적 오류**: 각 공이 나올 가능성은 같지만, 흰 공과 검은 공의 개수가 다르므로 색깔별 가능성은 같지 않음!
    - **올바른 확률**: 전체 공 $10$개 중 흰 공 $4$개이므로 $p = \frac{4}{10} = \frac{2}{5} = 0.4$ (또는 $40\%$).

### 2. 60fps 캔버스 인터랙티브 시뮬레이터 구성
- **모드 1: 🎲 주사위 수학적 확률 분할 랩**:
  - 표본공간 6개 눈($1 \sim 6$) 주사위 면 렌더링.
  - 조건 필터: `홀수의 눈 {1,3,5}`, `짝수의 눈 {2,4,6}`, `소수의 눈 {2,3,5}`, `5 이상의 눈 {5,6}` 버튼 클릭 시 적격 눈 하이라이트 및 공식 연동 ($p = a/n$).
  - `🎲 주사위 굴리기` 클릭 시 회전·바운스 물리 애니메이션 후 나온 눈이 선택된 사건에 부합하는지 실시간 판정.
- **모드 2: 🔮 가영이의 오개념 교정 주머니 랩**:
  - 주머니 속 검은 공 6개($60\%$) + 흰 공 4개($40\%$) 입체 구슬 배치.
  - 가영이의 주장($1/2$) vs 수학적 실제 확률($4/10 = 2/5$) 시각적 대조 HUD.
  - `공 추출 시뮬레이션`: 100회 단위 고속 추출 시뮬레이션 가동 및 실제 추출 상대도수가 가영이의 주장($0.5$)이 아닌 수학적 확률($0.4$)에 정확히 수렴함을 증명.
- **상단 인터랙티브 컨트롤 패널 (`canvas-control-panel-2-2`)**:
  - `🎲 주사위 확률 랩`, `🔮 가영이의 오류 랩`, `🎲 주사위 굴리기`, `🔄 리셋` 및 실시간 상태 배지 정상 동작 확인.
  - (심사 중 발견된 컨트롤 패널 DOM 중첩 결함을 즉시 교정하여 형제 요소로 정상 분리 완료)

### 3. 탐구 활동 4문항 채점 엔진 (Q1~Q4)
1. **문항 1 (문제 1-1 - 홀수의 눈 확률)**: 1개의 주사위를 던질 때 홀수가 나올 확률 $\to$ **`1/2`** (또는 `3/6`, `0.5`).
2. **문항 2 (문제 1-2 - 소수의 눈 확률)**: 1개의 주사위를 던질 때 소수가 나올 확률 $\to$ **`1/2`** (또는 `3/6`, `0.5`).
3. **문항 3 (생각 열기 - 흰 공 4개, 검은 공 6개)**: 흰 공 1개를 꺼낼 올바른 수학적 확률 $\to$ **`2/5`** (또는 `4/10`, `0.4`, `1/5` 등 유연 인정).
4. **문항 4 (확률 기호)**: 확률을 나타내는 대표적인 영문 기호 (Probability의 첫 글자) $\to$ **`p`** (또는 `P`).
- **채점 결과**: 4개 문항 모두 정답 시 100점 피드백 카드 가시화 및 Confetti 축하 애니메이션 발동 완비.
