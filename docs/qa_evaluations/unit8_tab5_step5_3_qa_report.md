   - `Mode 2 (lotto)`: 1,000원 복권 기댓값 계산기 (1등 10,000원×5% = 500원, 2등 2,000원×20% = 400원 ➔ 총 기댓값 900원) 및 100회 광속 긁기 누적 지출(10만원) vs 당첨금(9만원) 손익 그래프.
