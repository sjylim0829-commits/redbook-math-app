- **학습 내용**:

  - **개념 정리 (257쪽)**: 동일한 조건에서 실험이나 관찰을 여러 번 반복할 때, 어떤 사건이 일어나는 **상대도수가 일정한 값에 가까워지면**, 이 일정한 값을 그 사건이 일어날 **확률**이라고 한다.
  - **대수의 법칙 (Law of Large Numbers)**: 시행 횟수를 50회, 100회, 500회, 1000회로 늘릴수록 앞면이 나오는 상대도수는 $0.5$ ($1/2$)에 한없이 가까워짐.

  - $y$축 (상대도수): $0.0 \sim 1.0$ 눈금선.
  - **황금빛 기준선 ($y = 0.5$, 점선)**: 수학적 확률 $P = 1/2$ 기준선 명시.
  - 실시간 상대도수 꺾은선 궤적: 시행 횟수가 적을 때는 큰 진폭으로 변동하다가, 횟수가 증가함에 따라 $0.5$ 점선에 좁혀져 완벽하게 수렴하는 시각적 궤적 렌더링.

### 3. 탐구 활동 4문항 채점 엔진 (Q1~Q4)
1. **문항 1 (상대도수의 수렴 값)**: 동전을 던지는 횟수를 늘릴 때 앞면이 나오는 상대도수가 가까워지는 일정한 값 $\to$ **`0.5`** (또는 `1/2`).
2. **문항 2 (확률의 정의 용어)**: 상대도수가 가까워지는 이 일정한 값을 부르는 용어 $\to$ **`확률`**.
3. **문항 3 (대수의 법칙 이해)**: 100번 던졌을 때의 올바른 설명 $\to$ **`2`** (항상 50번은 아니지만 횟수를 늘릴수록 50%에 가까워짐).
4. **문항 4 (상대도수 실제 계산)**: 200번 중 앞면 105번의 상대도수 ($105 \div 200$) $\to$ **`0.525`**.
