# 📘 교과서 기반 인터랙티브 수학 웹 애플리케이션 제작 규칙
(Textbook-to-Interactive Math Web App Generation Rules)

본 문서는 **중1 수학(좌표평면과 그래프: `g1_coordinate.html`)** 구현 사례를 바탕으로, 교과서 지면(이미지, 텍스트, 단원 내용)이 주어졌을 때 **영서중학교 디지털 수학 인터랙티브 웹 앱으로 자동 변환·개발하기 위한 핵심 아키텍처 및 상세 제작 표준**입니다.

---

## 1. 🧭 전체 개발 철학 및 변환 원칙

1. **지면 교과서의 완벽한 1:1 대화형 인터랙션화**:
   - 교과서의 모든 코너(되짚어보기, 생각열기, 본문 개념, 함께하기, 문제, 스스로 확인하기, 생각 넓히기)를 누락 없이 1:1 서브스텝(`SubStep`)으로 분할 매핑합니다.
   - 정적인 그림/도표/문제를 **학생이 직접 조작(드래그, 클릭, 슬라이더, 펜 드로잉)하고 즉각 피드백을 받는 동적 캔버스(Two.js / Canvas 2D)**로 전환합니다.
2. **5단계 탐구 순환(Inquiry Cycle) 구조 준수**:
   - `0. 되짚어보기` $\rightarrow$ `1. 생각열기/개념` $\rightarrow$ `2. 성질/정당화` $\rightarrow$ `3. 형성평가(스스로 확인하기)` $\rightarrow$ `4~5. 심화/생각 넓히기`
3. **독립 실행형 싱글 파일 번들(Single File Bundle)**:
   - 각 단원 페이지(`g1_coordinate.html` 등)는 단일 파일로 완전 동작하며, LMS 연동 SDK, KaTeX, Two.js, Web Audio API를 내장합니다.

## 3. 📐 좌표평면 및 기하 캔버스 구성 상세 규칙 (Canvas Engine)

### 3.1 좌표평면 그리드(Grid) 설계 규격
- **그리드 간격(Step)**: 기본 `step = 30px` 또는 `40px` 사용.
- **중심점(Center) 자동 정렬**:
  ```javascript
  const width = two.width, height = two.height;
  const step = 40;
  const centerX = Math.round(width / 2 / step) * step;
  const centerY = Math.round(height / 2 / step) * step;
  ```
- **좌표축 및 화살표**:
  - 메인 $x$축, $y$축: 굵기 `2.5px`, 색상 `#1e293b`.
  - 화살표: $x$축 우측 끝, $y$축 상단 끝에 뾰족한 삼각형 패스(`two.makePath`) 렌더링.
  - 축 라벨: $x$는 우측 끝 아래(이탤릭체, 18px), $y$는 상단 끝 왼쪽(이탤릭체, 18px).
  - 원점 $O$: 교점 좌하단(`cx - 14, cy + 14`)에 영문 대문자 `O` 표기 (숫자 0과 구분).
- **격자선(Grid Lines)**:
  - 1단위 보조 격자선: 굵기 `1px`, 색상 `#cbd5e1` 또는 `#e2e8f0`.
  - 눈금 수치 라벨: 짝수(-4, -2, 2, 4 등) 또는 주요 정수 눈금에 또렷한 텍스트(`#475569`, 13~14px) 표기.

### 3.2 사분면(Quadrant) 시각화 규칙
- **영역별 파스텔톤 배경색**:
  - 제1사분면 ($x>0, y>0$): 연주황/오렌지 `rgba(254, 215, 170, 0.40)`
  - 제2사분면 ($x<0, y>0$): 연보라/퍼플 `rgba(233, 213, 255, 0.40)`
  - 제3사분면 ($x<0, y<0$): 연초록/그린 `rgba(187, 247, 208, 0.40)`
  - 제4사분면 ($x>0, y<0$): 연하늘/블루 `rgba(186, 230, 253, 0.40)`
- **정답 스포일러 방지 원칙**:
  - 사분면 뱃지(상단 모서리 라벨)에는 '제1사분면'과 같은 **명칭만 표기**하고, 부호($(+, +)$ 등)는 미리 노출하지 않음. 학생이 탐구 후 직접 부호 표를 채우도록 설계.

### 3.3 인터랙티브 점(Point) 및 드래그 조작 규칙
1. **점 마커 가시성**:
   - 메인 점: 반경 7.5~8px 원, 채우기 테마색(`#4f46e5` 등), 외곽선 흰색(2px).
   - 터치 유도 아우라(Aura): 반경 16px, 반투명 테마색(`rgba(79, 70, 229, 0.15)`), 펄스 효과.
2. **수선의 발 가이드라인(Dashed Guide Lines)**:
   - 점 $P$에서 $x$축, $y$축으로 수선의 발 점선(`dashes: [4, 4]`, 굵기 1.5px)을 연결하여 현재 좌표를 직관적으로 판독 가능하게 구현.
3. **스마트 자석 스냅 (Magnetic Snapping)**:
   - 마우스/터치 위치를 격자 정수 단위로 즉시 반올림 스냅:
     ```javascript
     let rx = Math.round((mx - cx) / step);
     let ry = Math.round((cy - my) / step);
     // 좌표 제한 (캔버스 범위 초과 방지)
     rx = Math.max(-maxGrid, Math.min(maxGrid, rx));
     ry = Math.max(-maxGrid, Math.min(maxGrid, ry));
     ```
4. **다중 점 드래그 및 목표 검증**:
   - 복수 점(A, B, C, D)을 각각 드래그하여 목표 좌표에 배치하는 문항에서는 각 점의 목표 도달 여부를 실시간 뱃지(`점 A 완료!`, `점 B 배치하기`)로 즉각 피드백.

### 3.4 캔버스 클릭 점 찍기 (Plotting System)
- 순서쌍 점을 직접 찍는 단계(예: $4.3-2$)에서는 캔버스 클릭 이벤트를 통해 가장 가까운 격자점에 점을 추가/토글:
  - 이미 찍힌 점을 다시 누르면 삭제.
  - 현재 찍힌 점 개수를 실시간 인디케이터로 표시 (`3개 / 5개`).

### 3.5 투명 펜 드로잉 오버레이 레이어 (Drawing Canvas)
- 도형 작도, 보조선 긋기, 보물지도 탐구 등 필기가 필요한 단계(`2-7`, `2-8`)에서는 Two.js 캔버스 위에 `<canvas id="freehand-drawing-canvas">`를 투명 오버레이.
- 상단 툴바에 색상 선택(파랑, 빨강, 검정), 지우개, 드로잉 삭제 버튼 제공.
- 필요 없는 서브스텝에서는 자동으로 캔버스를 숨기고 마우스/터치 이벤트를 점 드래그 전용으로 격리.

## 4. 🔲 빈칸(Blank / Input) 설계 및 채점·검증 규칙

### 4.1 빈칸이 뚫려야 하는 5대 핵심 영역
1. **핵심 수학 개념 및 용어**:
   - 예: `좌표`, `순서쌍`, `x축`, `y축`, `좌표축`, `원점`, `좌표평면`, `x좌표`, `y좌표`, `변수`, `그래프`, `정비례`, `반비례`.
2. **수학적 기호 및 표준 표기법**:
   - 예: 점의 좌표 기호 `P(a)`, `P(a, b)`, 원점 기호 `(0, 0)`, 개별 점 좌표 `A(-5)`, `B(1)`.
3. **사분면 명칭 및 부호**:
   - 예: `제1사분면`, `제2사분면`, `제3사분면`, `제4사분면` 및 부호 `+`, `-`.
4. **수학적 불변량, 관계성, 비교 키워드**:
   - 예: "(132, 37)과 (37, 132)는 서로 ( 다르다 )", "항상 x좌표를 y좌표 ( 앞 )에 쓴다", "좌표축 위의 점은 어느 사분면에도 ( 속하지 않는다 )", "$x$가 증가하면 $y$도 ( 증가 )한다".
5. **단계별 연산 및 최종 해**:
   - 예: 표의 대응 수치(`12, 15, 18`), 수직선 대응 유리수(`-7/2` 또는 `-3.5`), 방정식의 해($a+3=0 \implies a=-3$), 도형의 넓이.

### 4.2 인풋 필드 UI 스타일 가이드
```html
<!-- 문맥 속 인라인 괄호 빈칸 -->
• 점 A의 좌표: ( <input type="text" id="p13-a" class="proof-input-text" style="width:120px;" placeholder="좌표 기호 입력"> )
```
- **클래스**: 반드시 `.proof-input-text` 클래스를 적용하여 통일된 디자인 유지.
- **적정 너비(Width)**:
  - 부호(`+`, `-`): `45px~55px` (가운데 정렬)
  - 단순 수치/짧은 단어: `65px~85px`
  - 순서쌍 기호(`P(a, b)`): `100px~130px`
  - 긴 설명형 빈칸: `120px~150px`
- **가이드 플레이스홀더 및 정답 미노출 원칙 (Zero Answer Leakage)**:
  - `placeholder="수 입력"`, `placeholder="용어 입력"`, `placeholder="좌표 기호 (예: P(a,b))"` 등 **입력 형식 가이드만 제시**.
  - **🚫 정답 직접 노출 절대 금지**: 해당 문제의 실제 정답(숫자, 계산값, 정답 텍스트)을 placeholder나 라벨 예시로 직접 노출하는 것은 학습 효과를 저해하므로 절대 금지합니다.
  - 서브에이전트 검증 루프에서 모든 placeholder의 정답 누출 여부를 상시 점검합니다.

### 4.3 채점 및 텍스트 정규화 엔진 (`normTxt`)
모든 텍스트 검증은 공백 및 대소문자 차이로 인한 억울한 오답을 방지하기 위해 정규화 함수를 필히 통과시킵니다:
```javascript
function normTxt(v) {
  return v ? v.trim().replace(/\s+/g, '').toUpperCase() : '';
}
```
- **유연한 정답 인정 규칙**:
  - **분수/소수 동시 허용**: `-7/2`, `-3.5`, `-7분의2` 모두 정답 처리.
  - **한국어 어미 변화 허용**: `다르다`, `다름`, `달라진다` $\rightarrow$ `.includes('다르') || .includes('다름')`.
  - **괄호 및 기호 표기 유연성**: `P(-4, 2)` 채점 시 `P(-4,2)`, `(-4,2)`, `P(-4, 2)` 등 유연한 정규식 또는 부분 포함 허용.
- **캔버스 조작과의 결합 검증**:
  - 텍스트 입력만 맞추는 것이 아니라, 캔버스 위의 점이 목표 위치로 이동했는지(`state.pointP.x === 2`) 동시 판정.

### 4.4 피드백 및 정답 확인 화면 전환
1. **오답 처리**:
   - `.proof-error-notice` 인라인 경고창 출력.
   - 단순 "틀렸습니다"가 아닌, **어느 부분을 다시 생각해보아야 하는지 구체적인 힌트(`hintMsg`)** 제공.
2. **정답 처리 (`renderVerifiedAnswerView`)**:
   - 정답 즉시 `.verified-answer-card`로 전환.
   - 수학적으로 정돈된 완벽한 해설 요약 제시.
   - [🚀 다음 단계로 진행하기 ➔] 버튼으로 자연스럽게 다음 서브스텝 이동.

## 6. 🚀 교과서 지면을 받았을 때의 신규 단원 자동 제작 파이프라인

사용자가 새로운 교과서 페이지(단원 내용)를 제공하면, 에이전트는 다음 6단계 프로세스를 엄격히 수행합니다:

1. **지면 정밀 해독 및 코너 추출**:
   - 제공된 페이지에서 도입 상황, 탐구 발문, 정의 박스, 주의/참고 팁, 연습 문제, 형성평가, 심화 코너를 추출.
2. **서브스텝 코드 및 타이틀 매핑**:
   - `0-1, 0-2...` (되짚어보기), `1-1, 1-2...` (소단원1), `2-1...` (소단원2)와 같이 위계적 코드 부여.
3. **캔버스 인터랙션 모델링**:
   - 어떤 요소를 드래그할 것인가? (점, 도형의 꼭짓점, 슬라이더)
   - 모눈 그리드 규격(step, 사분면 색상, 점선 가이드) 결정.
4. **빈칸 및 문항 설계**:
   - 핵심 용어, 공식, 기호, 성질, 계산 수치에 `.proof-input-text` 빈칸 배치.
   - `normTxt` 기반 유연한 채점 로직 및 친절한 힌트 메시지 작성.
5. **UI 통합 및 KaTeX 렌더링 검증**:
   - Split-view 레이아웃에 통합하고, 모든 수식에 LaTeX(`$x$`, `$\overline{AB}$`) 적용 후 `renderMathInPage()` 바인딩.
6. **Git 즉시 반영**:
   - 완성 즉시 `git add`, `git commit`, `git push` 실행.
