# 📐 중2 수학 5단계 대화형 탐구 웹 앱 (Git & GitHub Pages)

중학교 2학년 수학 '도형의 성질' 단원을 위한 5단계 대화형 탐구 웹 애플리케이션입니다.

## 🌟 주요 기능
1. **5단계 학습 과정**:
   - `0. 튜토리얼` (0-1: 점 찍기 ➔ 0-2: 선분 연결 ➔ 0-3: 꼭짓점 드래그 ➔ 0-4: 완수)
   - `1. 단원 학습` (삼각형 세 변의 길이 성질 탐구)
   - `2. 정리하기` (이등변삼각형 핵심 성질 퀴즈)
   - `3. 히든 미션` (둔각삼각형 미션 - 2단계 완료 시 동적 노출)
2. **좌측 SVG 좌표평면 & 우측 지시사항/질문**:
   - 옅은 정수 격자점 수직/수평선
   - 실시간 변의 길이 및 각도 동적 계산
3. **교사 접속 모드**:
   - 비밀번호 입력 인증 (비밀번호: `950420`)
   - 🔒 해제하여 모든 활동 자유 이동 및 학생 실시간 작업 화면 조회
